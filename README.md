## ðŸŽ¨ Customizing for your own use case

Purna Sai voice agent is just a demo. To point the same machinery at *your*
business â€” a restaurant, a gym, a support desk â€” you only touch three places
(full walkthrough in [`docs/05-add-a-client.md`](docs/05-add-a-client.md)):

1. **`prompts.py`** â€” rewrite Purna Sai's persona, tone, and what she's allowed to do.
   Keep the system prompt **short** (â‰¤2 kB) â€” it's the biggest latency lever.
2. **`data/*.json`** â€” replace `properties.json` with your own data (menu,
   services, availability). The agent reads it through a function tool, so it
   never bloats the prompt.
3. **`tools.py`** â€” adjust the function tools to your domain (e.g. `book_visit` â†’
   `book_appointment`), and set `AGENT_NAME` + language defaults in `.env`.

Deploy the same way, dial your number, done.
